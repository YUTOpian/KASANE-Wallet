# AIコーディングツールの内蔵ブラウザについて（EMBRACE 対策）

2026年10月29日に Forever Security が「EMBRACE」の名前で公表した研究（Codex・Claude Desktop・VS Code・Cursor・GitHub Copilot の内蔵ブラウザ）を受けた対策です。
研究の中身は、この文書では確かめていません（解説記事の整理に基づく）。製品ごとの修正状況は変わるので、各社の発表を見てください。

## 何が問題か（要点）

ふつうのブラウザの3つのルールが、AIコーディングツールの内蔵ブラウザでは守られていない場合がある、と報告されている。

1. ページはPCでコマンドを実行できない
2. ローカルで開いたファイルは、他のファイルを読めない（Web Worker 経由でディスク全体を読めた、という報告）
3. ページはアドレスバーを書き換えられない（偽のアドレスを見せられた、という報告）

KASANE Wallet に当てはめると、危ないのは次の場面。

- 内蔵ブラウザで KASANE を開き、ニーモニックを表示したりパスワードを入力したりする（AIが画面を読める、AIが操作するブラウザでは入力も見える）。
- KASANE を `file://` で開いている（`index.html` をダブルクリック）ブラウザと同じブラウザで、信頼できない HTML を開く（ブラウザによっては、ローカルファイルどうしで保存領域を共有する）。
- キーストアファイル・ニーモニックのメモ・秘密鍵を、AIツールが開いているフォルダに置く。AIのチャットに貼る。

## アプリで入れた対策

1. **内蔵ブラウザなどで開かれたら、起動時に警告を出す**（`src/lib/embeddedBrowser.ts`、`src/components/EmbeddedBrowserGate.tsx`、`src/main.tsx`）
   - 見つけるもの: Electron 製のアプリ（`Electron/`）、VS Code 系のエディタ・AIアプリの名前（`Code/` `Cursor/` `Windsurf/` `Codex/` `Claude/` など）、JetBrains の内蔵ブラウザ（JCEF）、自動操作されているブラウザ（`navigator.webdriver`・HeadlessChrome）、`window.process.versions.electron`（UAから名前が消されていても見つける）。
   - 見つけたら、アプリ本体を描画しない。ルーターもストレージの読み取りも、同意するまで動かない。
   - 画面には、理由、「いつものブラウザで開いてください」、そのアドレス（コピー付き）を出す。`file://` で開かれているときは、その注意も足す。
   - 「リスクを理解した上で続ける」にチェックを入れれば続けられる。同意は記憶しない（次に開いたらまた聞く）。続けたあとも、画面の左下に小さな「内蔵ブラウザ」の印を出し続け、押すと同じ警告を開き直せる。
   - すでに別のページの `<iframe>` に埋め込まれた場合は、これまでどおり `src/lib/frameGuard.ts` が止める（VS Code の Simple Browser はこれに当たる）。
2. **「安全な保管の知識」に1項目足した**（`wallet.safe_points`、5言語）: 内蔵ブラウザで開かない。ニーモニック・秘密鍵・キーストアを、AIのチャットに貼らない、AIが開いているフォルダに置かない。
3. 文言は ja・en・zh・ko・ru（`embedded.*`）。

## できないこと・限界

- 見つけるのはユーザーエージェントなどの手がかりだけ。名前が変わった新しいツールや、UAを書き換えたものは見つけられない。見つからなかったことは、安全の保証ではない。
- 内蔵ブラウザの外から、ページがKASANEの保存データを読むことは、アプリ側では防げない。保存データ（キーストア・ニーモニックの暗号文）は、パスワードで暗号化されている（総当たりへの強さはパスワード次第）。
- アドレスバーの偽装（Copilot の件）は、ブラウザ側の問題で、アプリでは見分けられない。KASANE のアドレスは、ブックマークから開く。

## 使う人のための対策（アプリの外）

- 内蔵ブラウザは、ふだんのブラウザの代わりに使わない。KASANE は Chrome・Edge・Safari などで自分で開く。
- AIが出してきたリンクや、プロジェクトの中の HTML を、無条件に開かない。知らないリポジトリを「READMEの通りにセットアップして」と丸投げしない。
- ニーモニック・秘密鍵・キーストアファイルを、AIツールが開いているフォルダに置かない。AIのチャットに貼らない。
- ツールを最新に更新する（Cursor は 10月1日以降、GitHub Copilot は最新版で修正済みと報告されている）。
- `.env` の鍵やトークンは使い回さず、漏れたらすぐ無効化できるようにしておく。SSH 鍵にはパスフレーズを付ける。
